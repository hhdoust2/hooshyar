🔒 گزارش امنیت هوشیار

بله — این پروژه با چند لایه محافظتی طراحی شده است:

کلید API فقط در localStorage مرورگر خودتان ذخیره می‌شود؛ هیچ سرور واسطی وجود ندارد و کلید به هیچ‌جا جز Groq ارسال نمی‌گردد.
همه درخواست‌ها مستقیم، رمزنگاری‌شده (HTTPS/TLS) و فقط به api.groq.com فرستاده می‌شوند — ارتباط با دامنه‌های دیگر توسط هدر CSP مسدود شده است.
برنامه کاملاً استاتیک است؛ با استقرار روی Vercel به‌صورت خودکار گواهی SSL رایگان می‌گیرید.
ورودی‌ها و پاسخ‌های مدل قبل از نمایش ضدعفونی (escape) می‌شوند تا خطر XSS صفر باشد.
اگر سایت را عمومی منتشر می‌کنید، کلید داخل مرورگر بازدیدکنندگان قابل مشاهده خواهد بود. برای این حالت کلید را روی پروکسی سرورلس Vercel بگذارید 👇
هرگز کلید را مستقیم داخل کد یا مخزن عمومی GitHub قرار ندهید؛ در Vercel از Environment Variables استفاده کنید.

نمونه پروکسی امن روی Vercel — فایل api/groq.js (کلید فقط سمت سرور می‌ماند):

// api/groq.js — Vercel Serverless Proxy
export default async function handler(req, res) {
  const r = await fetch(
    'https://api.groq.com/openai/v1/chat/completions',
    {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        Authorization: 'Bearer ' + process.env.GROQ_API_KEY
      },
      body: JSON.stringify(req.body)
    }
  );
  res.status(r.status);
  r.body.pipe(res);
}

🔑 ثبت کلید API

کلید رایگان خود را از console.groq.com دریافت کنید. 🔒 کلید فقط در localStorage مرورگر شما ذخیره می‌شود و به هیچ سروری جز Groq ارسال نمی‌گردد.

🚀 استقرار روی GitHub + Vercel

  1. این فایل را با نام index.html در یک مخزن جدید GitHub پوش کنید.
  2. در vercel.com گزینه New Project را بزنید و مخزن را Import کنید.
  3. Framework را روی Other بگذارید و Deploy را بزنید.
  4. تمام! پروژه روی آدرس your-app.vercel.app با SSL رایگان در دسترس است. ✅

نکته امنیتی: برای سایت عمومی، طبق «گزارش امنیت» از پروکسی سرورلس استفاده کنید تا کلید مخفی بماند.
