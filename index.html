متن طولانی به قطعه‌های کوچک تقسیم می‌شود و قطعه‌ها یکی‌یکی و با فاصله‌ی مناسب (۶۰ ÷ RPM ثانیه) فرستاده می‌شوند. اگر Groq خطای محدودیت (۴۲۹) بدهد، برنامه خودش صبر می‌کند و دوباره تلاش می‌کند. Groq سقف توکن در دقیقه را روی مقدار «max_tokens» اعلام‌شده حساب می‌کند، بنابراین برنامه برای هر قطعه سقف خروجی را کوچک نگه می‌دارد و سهم توکن را پیگیری می‌کند. مقدار دقیق RPM/TPM/TPD مدل خود را از بخش Limits در console.groq.com ببینید. متن مبدأ و ترجمه‌های انجام‌شده فقط در حافظه‌ی همین مرورگر (IndexedDB) نگه داشته می‌شوند و با «پاک کردن» یا «شروع از اول» حذف می‌شوند.

🔒 گزارش امنیت هوشیار

بله — این پروژه با چند لایه محافظتی طراحی شده است:

کلید API فقط در localStorage مرورگر خودتان ذخیره می‌شود و در هیچ پایگاه‌داده‌ای نگه‌داری نمی‌شود.
درخواست‌ها از طریق پروکسی همین سایت (api/groq.js روی Vercel) به Groq می‌رسند. پروکسی کلید را فقط برای همان درخواست به کار می‌برد، ذخیره یا لاگ نمی‌کند و فقط درخواست‌هایی را می‌پذیرد که از خودِ همین سایت آمده باشند.
همه ارتباط‌ها رمزنگاری‌شده (HTTPS/TLS) است و هدر CSP فقط ارتباط با همین سایت و api.groq.com را مجاز می‌کند.
پیشرفت ترجمه‌ی فایل‌های بزرگ (متن مبدأ و ترجمه) فقط در IndexedDB مرورگر خودتان ذخیره می‌شود؛ می‌توانید در تنظیمات ترجمه آن را خاموش کنید.
فایل‌های Word و PDF فقط داخل مرورگر خودتان خوانده می‌شوند و جایی آپلود نمی‌شوند. اگر پوشه‌ی vendor/ کنار سایت نباشد، دو کتابخانه‌ی خواندن (pdf.js و mammoth) از cdn.jsdelivr.net بارگذاری می‌شود.
ورودی‌ها و پاسخ‌های مدل قبل از نمایش ضدعفونی (escape) می‌شوند تا خطر XSS صفر باشد.
کلید شما در هر درخواست از سرور Vercel عبور می‌کند. کلید شخصی را فقط روی سایتی وارد کنید که خودتان مستقر کرده‌اید یا به آن اعتماد دارید.
اگر سایت بدون پروکسی (مثلاً GitHub Pages) اجرا شود، برنامه مستقیم به Groq وصل می‌شود که در ایران بدون فیلترشکن کار نمی‌کند.
هرگز کلید را مستقیم داخل کد یا مخزن عمومی GitHub قرار ندهید.

🔑 ثبت کلید API

کلید رایگان خود را از console.groq.com دریافت کنید. 🔒 کلید فقط در localStorage مرورگر شما ذخیره می‌شود و هنگام هر درخواست، از طریق پروکسی همین سایت (بدون ذخیره یا لاگ) به Groq می‌رسد.

🚀 استقرار (دو روش، هر کدام با پروکسی داخلی)

روش ۱ — Vercel

  1. سه فایل index.html، api/groq.js و vercel.json را در یک مخزن GitHub پوش کنید.
  2. در vercel.com مخزن را Import کنید، Framework را Other بگذارید و Deploy بزنید.

روش ۲ — Cloudflare Workers

  1. سه فایل wrangler.jsonc، src/worker.js و public/index.html را در یک مخزن GitHub پوش کنید.
  2. در dash.cloudflare.com به Workers & Pages بروید، Create → Import a repository را بزنید و مخزن را Deploy کنید (یا در ترمینال npx wrangler deploy).

در هر دو روش نیازی به Environment Variable نیست و کلید را همین‌جا در برنامه ثبت می‌کنید. اگر آدرس vercel.app یا workers.dev در شبکه شما باز نمی‌شود، یک دامنه شخصی به پروژه وصل کنید.
